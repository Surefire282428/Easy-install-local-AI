# LocalAI Setup Wizard

An interactive setup assistant that guides you through installing a local AI model on your PC – fully private, offline, and with no subscription fees.

Powered by Ollama, the open-source tool for running large language models locally.

## Features

- Step-by-step workflow: select your operating system, specify your RAM, and choose a compatible model.
- Automatic model filtering – only models that fit your hardware are shown.
- Copy-ready terminal commands for Windows, macOS, and Linux.
- Single HTML file – no external dependencies, works in any modern browser.

## Getting Started

1. Download `index.html` or clone this repository.
2. Open the file in your browser (double-click or "Open with...").
3. Follow the on-screen instructions – the wizard generates the correct commands for your system.

## Usage

The wizard provides the exact commands for your OS. Copy them, paste into your terminal, and press Enter. After a few minutes, your first local AI model is ready to use.
